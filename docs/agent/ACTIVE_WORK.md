# PepCLIP Active Work Claims

Last checked: 2026-07-26

Add one row before changing files or launching a run. Remove it after the
handoff is written. A scope must identify exact files or a dedicated output
directory; broad scopes such as `phase3/` are invalid.

| Session / owner | Task | Source-file scope | Output-directory scope | Started | Status |
|---|---|---|---|---|---|
| None | No active claimed work | - | - | - | idle |

Two sessions may proceed in parallel only when both source-file and output
scopes are disjoint. An already-open session must re-read this table before
expanding its scope.
