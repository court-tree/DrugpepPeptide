# Phase-3 Documentation Index

Use this directory for Phase-3 design and communication artifacts.

## algorithm/

Algorithm drafts, version plans, and formal logic documents.

Put the next simplified Phase-3 dataset algorithm here, for example:

```text
phase3_finetune_dataset_algorithm_v1.md
```

## sources/

Data-source notes, source inclusion/exclusion decisions, and database-specific
assumptions.

## presentations/

Slide decks, slide content drafts, presentation build scripts, and rendered
inspection files.

Presentation artifacts should not be placed in the Phase-3 root directory.
